# Atmosphere Pass 001

Goal: make the first 60 seconds memorable.

Do not:
- refactor architecture
- add combat
- add inventory
- let player leave the truck
- rebuild existing systems

Improve:
- warm cabin lighting
- cold outside fog/snow
- dashboard glow
- windshield feeling
- radio text/messages
- lived-in cabin details
- first road event timing

Opening sequence:
1. player starts seated in warm cabin
2. engine already running
3. road moves through snow
4. after 10 seconds radio crackles
5. disturbing short transmission appears
6. distant lights appear outside
7. cabin lights flicker once

Done when:
- first 60 seconds feel cinematic
- project still runs
- DESIGN.md updated
- TASKS.md updated
